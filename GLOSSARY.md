# Forte Datathon '26: проверка кассовой дисциплины по видео

Локальный сервис, который по видео кассы находит визуально наблюдаемые признаки возможных нарушений и указывает, где смотреть и какой пункт норматива применим.

## Результат проверки

**Видео**:
Один загруженный файл .mov с одной камеры над одной кассой. Единица, по которой жюри считает вердикт.
_Avoid_: ролик, запись, файл (в разговоре о модели), клип в API

**Вердикт**:
Итог по всему видео: `violation` («Обнаружены признаки возможных нарушений») или `no_violation` («Нарушение не обнаружено»). Третьего значения нет.
_Avoid_: решение, заключение, «недостаточно данных»

**Нарушение**:
Одно событие в видео с визуально наблюдаемыми признаками несоблюдения пункта норматива. У него есть тип, таймкод, описание и кадры-доказательства. Это подсказка проверяющему, а не юридический вывод.
_Avoid_: инцидент, событие (как синоним), аномалия

**Таймкод**:
Момент нарушения, который сервис сообщает в секундах от начала видео. Совпадает с `timestamp_sec` первого кадра-доказательства.
_Avoid_: таймстемп, время события, метка (это разные вещи)

**Окно**:
Короткий отрезок видео фиксированной длины, который модель оценивает целиком и которому ставит один скор. Окна идут внахлёст.
_Avoid_: сегмент, фрагмент, чанк

**Ракурс**:
Положение камеры в помещении. Все обучающие видео сняты одной камерой сверху (FAQ 3), финальное видео жюри снято под другим углом (FAQ 4). Мебель и положение кассира ракурс не меняют, для них есть «Расстановка».
_Avoid_: угол, вид, камера (для положения)

**Расстановка**:
Как стоят стол и сейф и сидит ли кассир лицом или спиной к камере. При одном ракурсе у обучающих видео две расстановки. Это единица для проверки на невиданной расстановке (#38).
_Avoid_: ракурс (ракурс про камеру), сцена, комната

**Сцена**:
Видео, снятые подряд с теми же людьми, одеждой и предметами: видео с нарушением и его чистый дубль. Единица фолда при проверке модели, иначе дубль остаётся в обучении (`data/scenes.csv`, ADR 0006).
_Avoid_: расстановка (это мебель), дубль (это одно видео сцены)

**Метка**:
Строка разметки: видео, «нарушение / без нарушения», для нарушения одна секунда (целое число) и тип нарушения. Секунду дали организаторы, тип поставила команда, посмотрев видео. Это эталон, с которым сравнивается таймкод.
_Avoid_: лейбл, таймстемп, разметка (для одной строки)

**Тип нарушения**:
Наше название нарушения из `docs/TYPES.md`, записанное словами сценария, который виден в видео, и привязанное к пункту норматива. Если ни один тип не подходит, ставится «Иное подозрительное действие».
_Avoid_: класс, категория, вид нарушения

**Скрытая категория**:
Категория нарушения, которую организаторы задали видео и с которой жюри сравнивает наш тип нарушения. Список категорий жюри не раскрывает.
_Avoid_: категория (без уточнения), эталонный тип, класс жюри

**Эвристика**:
Наша проверка по наблюдаемым фактам (люди, предметы, деньги, пустая комната). Она выбирает тип нарушения и может сама поднять вердикт. К нормативу отношения не имеет.
_Avoid_: правило (без уточнения)

**Кадр-доказательство**:
Кадр из видео в формате JPEG, по которому человек может проверить нарушение. На одно нарушение от одного до трёх.
_Avoid_: скриншот, превью, evidence

## Нормативная база

**Пункт**:
Конкретный пункт или раздел нормативного акта РК (НБРК, adilet.zan.kz), на который ссылается тип нарушения.
_Avoid_: статья, норма (без номера), правило (без уточнения)

**Ближайшая норма**:
Пункт, который регулирует тот же предмет, что и нарушение, но прямо его не запрещает. На него ссылаются, только если описание называет один видимый факт.
_Avoid_: аналогия, похожий пункт, точный пункт (для такой ссылки)
