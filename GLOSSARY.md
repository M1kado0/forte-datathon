# Forte Datathon '26: проверка кассовой дисциплины по видео

Локальный сервис, который по видео кассы находит визуально наблюдаемые признаки возможных нарушений и указывает, где смотреть и какой пункт норматива применим.

## Результат проверки

**Видео**:
Один загруженный файл .mov с одной камеры над одной кассой. Единица, по которой жюри считает вердикт.
_Avoid_: ролик, запись, файл (в разговоре о модели), клип в API

**Вердикт**:
Итог по всему видео: `violation` («Обнаружены признаки возможных нарушений») или `no_violation` («Нарушение не обнаружено»). Третьего значения нет.
_Avoid_: решение, заключение, «недостаточно данных»

**Нарушение**:
Одно событие в видео с визуально наблюдаемыми признаками несоблюдения пункта норматива. У него есть тип, таймкод, описание и кадры-доказательства. Это подсказка проверяющему, а не юридический вывод.
_Avoid_: инцидент, событие (как синоним), аномалия

**Таймкод**:
Момент нарушения, который сервис сообщает в секундах от начала видео. Совпадает с `timestamp_sec` первого кадра-доказательства.
_Avoid_: таймстемп, время события, метка (это разные вещи)

**Окно**:
Короткий отрезок видео фиксированной длины, который модель оценивает целиком и которому ставит один скор. Окна идут внахлёст.
_Avoid_: сегмент, фрагмент, чанк

**Ракурс**:
Положение камеры относительно кассы. В обучающих видео их несколько, финальное видео жюри снято с нового.
_Avoid_: угол, вид, камера (для положения)

**Метка**:
Строка разметки организаторов: видео, «нарушение / без нарушения» и для нарушения одна секунда (целое число). Это эталон, с которым сравнивается таймкод. Типа в метке нет.
_Avoid_: лейбл, таймстемп, разметка (для одной строки)

**Тип нарушения**:
Одна из категорий нарушений из `docs/TYPES.md`, привязанная к пункту норматива. Если ни одна не подходит, ставится «Иное подозрительное действие».
_Avoid_: класс, категория, вид нарушения

**Эвристика**:
Наша проверка по наблюдаемым фактам (люди, предметы, пустая комната), которая выбирает тип нарушения. К нормативу отношения не имеет.
_Avoid_: правило (без уточнения)

**Кадр-доказательство**:
Кадр из видео в формате JPEG, по которому человек может проверить нарушение. На одно нарушение от одного до трёх.
_Avoid_: скриншот, превью, evidence

## Нормативная база

**Пункт**:
Конкретный пункт или раздел нормативного акта РК (НБРК, adilet.zan.kz), на который ссылается тип нарушения.
_Avoid_: статья, норма (без номера), правило (без уточнения)
