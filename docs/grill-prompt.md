Грилл по плану решения кейса ForteBank перед path lock. Жёсткий лимит 25 минут.

## Источники (прочитай сам до первого раунда)
- `docs/BRIEF.md`: бриф, источник истины по требованиям.
- `docs/acceptance.md`: бриф, разобранный в чек-лист `TZ-x.y`, и критерии оценки.
- `docs/PLAN.md`: подход, таймлайн, роли, тикеты T01–T14, раздел "Grill agenda".
- `docs/QUESTIONS.md`: вопросы организаторам с ответами по умолчанию.
- `AGENTS.md`: ограничения команды.
- `data/raw/open_labels.xlsx` и `data/raw/videos/`: разметка и клипы (42 файла).

Если `docs/BRIEF.md` нет, сконвертируй docx командой выше.

## Цель
Закрыть решения, без которых нельзя написать спек и тикеты. Результат грилла: общее понимание,
`GLOSSARY.md` и ADR в `docs/adr/`. Код не пишем.

## Повестка (дерево решений)
1. Машина для сервинга: RTX 5070 на Windows через cloudflared или Mac M1 8 GB. Кто P2.
2. Ноутбук плюс туннель или своя VM (зависит от ответа организаторов, `QUESTIONS.md` #8).
3. Dev-окружение на Windows: Git Bash или WSL, дубли целей Makefile через `uv run`.
4. Подход по `PLAN.md` "Approach": ветка A (эмбеддинги кадров + классификатор окон),
   ветка B (детектор людей + поза + объекты + правила). Что входит в mvp0, что в mvp1.
5. Определения для оценки: что такое окно, как считаем таймкод (пик или начало), сколько нарушений
   может быть в одном видео, как выбираем 1–3 кадра-доказательства.
6. Таксономия типов (4–7 штук): какие ловим правилами, какие классификатором, fallback
   "Иное подозрительное действие". Зависит от T04, задавай последним раундом.
7. Связь тип → документ НБРК, пункт, цитата, URL. Какие типы исключаем по TZ-7.1
   (нужны невидимые данные).
8. Бюджет времени: ≤ 60 с на клип при 5 параллельных задачах. Что режем, если не влезаем.

## Правила раунда
- Факты добываешь сам: файлы, разметка, `uv run`, субагент. Меня спрашиваешь только о решениях.
- Каждый вопрос со ссылкой на `TZ-x.y` или критерий оценки. Вопрос без ID брифа не задаём.
- Если ответ требует запуска кода (скорость на CPU, разделимость эмбеддингов), не решай его в грилле.
  Запиши как гипотезу для тикета T02 или T03 и иди дальше.
- Термины фиксируй в `GLOSSARY.md`: нарушение, тип нарушения, видео/клип, окно, таймкод,
  кадр-доказательство, вердикт, правило, пункт. Одно слово на одно понятие.
- ADR только для решений, которые дорого переиграть: машина сервинга, выбор моделей, политика порога,
  таксономия типов.
- На 20-й минуте останови раунды. Выведи список открытых вопросов, у каждого ответ по умолчанию,
  и попроси подтвердить всё одним "да".
