## Memorable moment — candidates (pick ONE)
1. Live what-if flip: «Двигаем один ползунок — и клиент из „отказать" становится „одобрить".»
2. A named segment that sticks: «{{"Тихие должники"}} — {{N}} клиентов, {{₸}}».
3. One striking ₸ number.
4. A short, light line about the team.
