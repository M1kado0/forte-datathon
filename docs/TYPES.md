# Типы нарушений

Собрано командой `uv run python -m src.rules.types_doc` (входит в `make all`) из `src/rules/rules.yaml` и `data/labels.csv` (типы в нём берутся из `data/violation_types.csv`). Руками не правим.
Тип называем словами сценария из видео, норма идёт в пункт (ADR 0005). В описании стоит только то, что видно в кадре; `[предмет]` стоит там, где эвристика подставляет название предмета, найденного в кадре.
Число меток считается по 22 меткам нарушений в `data/labels.csv`, у типа без примеров стоит 0.

|---|---|---|---|---|
| `keys_left_on_safe` | Ключи оставлены на сейфе | Кассир вышла из помещения, оставив ключ на сейфе. | Правила № 231, п. 80 | 2 |
| `safe_left_open` | Сейф оставлен открытым | Кассир достала наличные из сейфа и оставила дверцу сейфа открытой. | Правила № 231, п. 20, часть вторая | 1 |
| `cash_left_on_desk` | Наличные оставлены на столе вместо сейфа | Кассир вышла из помещения, оставив наличные на столе вне закрывающегося устройства. | Правила № 231, п. 20, часть вторая | 1 |
