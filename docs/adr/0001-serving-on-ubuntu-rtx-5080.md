# Сервис для жюри работает на Ubuntu с RTX 5080 (16 GB)

Жюри шлёт видео в наш API, а облачные AI-сервисы запрещены (TZ-7.3, FAQ 21, 22). Поэтому модели работают на машине команды. Выбрали Ubuntu с RTX 5080 (16 GB VRAM, драйвер 595.99.02, CUDA 13.2 по `nvidia-smi` 17.10): на ней одна очередь и один GPU-воркер укладываются в ≤ 45 с на видео длиной 145 с. Mac M1 8 GB остаётся CPU-резервом. Windows-машины только для разработки.

## Consequences

- RTX 50xx (Blackwell) работает только с PyTorch ≥ 2.7. Индекс `cu128` заканчивается на torch 2.11, а текущий стабильный torch 2.14.x выходит под `cu132` (`docs/research/models.md`, раздел 3). Драйвер 595.99.02 поддерживает CUDA 13.2, поэтому в T02 torch закрепляется на индекс `cu132` для Linux. На macOS ставится обычная сборка с PyPI.
- 16 GB VRAM хватает для детектора, позы и эмбеддингов одновременно. Локальная VLM (Qwen2.5-VL-7B-AWQ, около 6.9 GB весов) возможна, но остаётся в stretch.
- Модуль ядра nvidia собирается под конкретное ядро. После обновления ядра проверять `nvidia-smi`; если драйвер не отвечает, ставить `linux-modules-nvidia-595-open-$(uname -r)`.
- Сервинг-машина не должна засыпать и обновляться с 11:00 до объявления результатов.
