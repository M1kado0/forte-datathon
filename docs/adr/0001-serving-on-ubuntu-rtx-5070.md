# Сервис для жюри работает на Ubuntu с RTX 5070 (12 GB)

Жюри шлёт видео в наш API, а облачные AI-сервисы запрещены (TZ-7.3, FAQ 21, 22). Поэтому модели работают на машине команды. Выбрали Ubuntu с RTX 5070 (12 GB VRAM): на ней одна очередь и один GPU-воркер укладываются в ≤ 45 с на видео длиной 145 с. Mac M1 8 GB остаётся CPU-резервом. Windows-машины только для разработки.

## Consequences

- RTX 50xx (Blackwell) работает только с PyTorch ≥ 2.7, собранным под CUDA 12.8 (`cu128`). В T02 torch закрепляется на индекс cu128 для Linux.
- 12 GB VRAM хватает для детектора, позы и эмбеддингов одновременно. Локальная VLM (Qwen2.5-VL-7B в 4-bit, около 6 GB) возможна, но остаётся в stretch.
- Сервинг-машина не должна засыпать и обновляться с 11:00 до объявления результатов.
